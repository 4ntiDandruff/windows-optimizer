Windows Debloater v2.4: Mengapa Laptop Butuh Debloat?

Instalasi standar Windows 10 dan Windows 11 saat ini memuat puluhan aplikasi bawaan (UWP bloatware), layanan pelacakan analitik (telemetry), serta fitur background yang membebani memori RAM dan disk I/O. Pada prosesor hemat daya (Intel Core i3 generasi lama, Celeron, AMD A-Series, atau Ryzen generasi awal) dan penyimpanan HDD/eMMC, beban latar belakang ini memicu disk usage 100% dan respon sistem yang lambat.

Windows Debloater v2.4 dari MEGAPASS dirancang khusus oleh teknisi hardware bersertifikasi BNSP di meja servis Sidoarjo untuk membersihkan seluruh beban sistem tersebut secara terukur, otomatis, dan fail-safe.

28 Modul Optimasi & Pelaporan Sistem

Berikut alur kerja komprehensif dari modul 0 hingga 28:

0. Buat Restore Point Otomatis

Mengaktifkan System Restore pada drive C: dan membuat checkpoint rollback berlabel MEGAPASS Debloat dengan bypass batas cooldown 24 jam via registry.

0.5. Baseline Snapshot WMI/CIM

Mencatat kondisi riil sebelum debloat: jumlah RAM terpakai, total proses aktif, service yang sedang berjalan, dan sisa ruang kosong drive C: untuk laporan komparasi.

1. Pembersihan 60+ Bloatware Apps

Menghapus aplikasi UWP yang tidak diperlukan (termasuk LinkedIn, Microsoft To-Do, Clipchamp, paket sponsor OEM) pada seluruh profil user dan memblokir instalasi ulang via provisioned package list serta mematikan Start Menu cloud content stubs.

2. Matikan Telemetry & Data Collection

Menghentikan scheduled tasks pengirim diagnostic data (CEIP, WER, DiagTrack) ke server analitik.

3. Matikan Cortana, Copilot & Recall

Menonaktifkan web search Cortana, tombol Copilot pada taskbar, serta fitur screenshot otomatis Recall di Windows 11 24H2.

4. Matikan Iklan & Suggestions

Menonaktifkan rekomendasi aplikasi dan iklan promosi di Start Menu, Lock Screen, dan File Explorer.

5. Perkuat Privasi Sistem

Mematikan Advertising ID, pelacakan lokasi geolokasi, sinkronisasi clipboard cloud, dan pengiriman sampel tulisan tangan.

6. Matikan Background Apps

Memutus izin eksekusi aplikasi UWP di background secara global untuk menghemat siklus CPU dan baterai laptop.

7. Matikan 20 Background Service Berat

Menonaktifkan service yang sering memicu disk usage 100%: DiagTrack, SysMain (Superfetch), Windows Search (WSearch), Xbox Live services, WerSvc, CDPSvc, DPS, dan Delivery Optimization (DoSvc). Service notifikasi WpnService dipertahankan agar Focus Assist Priority Only dan Action Center tetap berfungsi stabil.

8. Optimasi Performa & Power Plan

Menyetel Visual Effects ke mode Custom meja servis: mempertahankan font halus (ClearType sub-pixel smoothing), thumbnail Explorer, translucent selection, bayangan label desktop, drag window, serta kontrol animasi jendela esensial, sembari mematikan transparansi dan efek berat lainnya untuk efisiensi render CPU/GPU. Otomatis mengaktifkan Focus Assist ke mode Priority Only (via WNF broadcast & registry) agar pengguna tidak diganggu popup spam.

9. Perkuat Network Privacy

Mematikan Wi-Fi Sense, update P2P delivery antar-komputer lokal, Remote Assistance tanpa izin, dan autoplay removable media.

10. Bersihkan Explorer & Taskbar

Konfigurasi Explorer profesional:

  • Default Buka ke This PC: File Explorer terbuka langsung menampilkan daftar partisi harddisk/SSD dan drive komputer, bukan Quick Access atau Home.
  • Tombol Task View Dimatikan: Menghilangkan tombol Task View pada taskbar untuk ruang taskbar yang lebih lega.
  • Hidden Files Tetap Aman (Disembunyikan): File sistem dan folder tersembunyi sengaja tetap disembunyikan agar pengguna awam tidak salah hapus file sistem Windows krusial.
  • Ekstensi File Dikenal Disembunyikan: Opsi bawaan Hide extensions for known file types aktif tercentang untuk kenyamanan visual antarmuka pengguna sehari-hari.
  • Widgets, Chat & Searchbox Taskbar Disesuaikan: Tampilan antarmuka desktop bersih, widget cuaca nonaktif, dan search box panjang penuh tetap tersedia.

11. Kontrol Windows Update Manual

Mencegah forced restart otomatis saat laptop sedang dipakai bekerja serta mengubah instalasi Microsoft Store ke mode manual.

12. Deep Cleanup (Temp, Cache, Residue)

Membersihkan folder Temp, Prefetch, SoftwareDistribution\Download, DeliveryOptimization cache, thumbnail cache, dan mengosongkan Recycle Bin semua drive (membebaskan 500MB hingga 5GB+ ruang penyimpanan).

13. Jeda Windows Update Hingga 2099 & Target Version Lock

Menjeda jadwal update otomatis hingga tahun 2099, mengunci versi Windows saat ini, dan menerapkan kebijakan NoAutoUpdate di Group Policy, dengan service wuauserv tetap disetel Manual agar Microsoft Store tetap 100% aktif menginstal dan memperbarui aplikasi.

14. Matikan SmartScreen & Phishing Filter

Menonaktifkan SmartScreen dan filter phishing web untuk menghilangkan popup peringatan keamanan berlebih saat membuka aplikasi utilitas pihak ketiga, sementara Windows Defender tetap dibiarkan 100% aktif dan utuh tanpa disentuh sama sekali.

15. Kembalikan Klik Kanan Klasik Windows 11

Mengaktifkan context menu klasik Windows 11 secara instan tanpa perlu lagi klik "Show more options".

16. Matikan Reserved Storage (~7GB)

Mengembalikan ruang partisi ~7GB yang biasanya dicadangkan sistem untuk update Windows melalui DISM.

17. Matikan VBS & Memory Integrity (HVCI)

Menonaktifkan Virtualization-Based Security yang menyedot performa prosesor lama, memberikan lonjakan responsivitas 5-15%.

18. Matikan Edge Startup Boost & Background

Mencegah Microsoft Edge berjalan diam-diam sejak sistem pertama kali booting.

19. OneDrive Dipertahankan Utuh

OneDrive dipertahankan utuh tanpa mematikan proses, tanpa mencabut dari startup, dan tanpa menyentuh sinkronisasi cloud agar file dokumen dan desktop tetap tersinkronisasi normal.

20. Optimasi Pagefile Dinamis

Mendeteksi kapasitas RAM fisik dan mengatur ukuran virtual memory pagefile secara tetap (1.5x RAM fisik, batas aman 8GB) untuk meniadakan fragmentasi disk.

21. Matikan Search Indexer Scheduled Tasks

Mematikan tugas indexing otomatis yang kerap membebani harddisk mekanik (disarankan gunakan Everything search untuk pencarian instan).

22. Optimasi NTFS & Disk I/O

Menonaktifkan pencatatan timestamp akses terakhir (disablelastaccess) dan nama pendek 8.3 untuk meringankan overhead NTFS hingga 20%.

23. Percepat Boot & Shutdown

Menurunkan timeout service dan aplikasi yang macet dari 5 detik menjadi 2 detik serta mengaktifkan AutoEndTasks.

24. Matikan Storage Sense Auto-Run

Mencegah sistem menghapus file di folder Downloads dan Recycle Bin secara sepihak.

25. Hapus Network Throttling

Membuka limit reservasi bandwidth 80% Windows dan mematikan algoritma Nagle (TCP No Delay) pada adapter jaringan untuk latency browsing yang lebih rendah.

26. Tingkatkan Responsiveness UI

Mengatur MenuShowDelay ke 0ms (respons menu klik kanan seketika), mematikan animasi minimize/maximize, dan mematikan cursor blink overhead.

27. Post-Debloat Snapshot

Mengambil data metrik pasca-eksekusi dan menghitung selisih (delta) penghematan RAM, pengurangan proses latar belakang, dan penambahan kapasitas disk C:.

28. Auto-Generate Laporan HTML di Desktop

Membuat file laporan interaktif MEGAPASS-Debloat-Report.html langsung di Desktop pengguna dan membukanya otomatis di browser.

Fitur Baru: Auto-Generate Laporan HTML Before-After

Salah satu pembaruan terbesar pada versi 2.4 adalah pembuatan laporan visual otomatis. Begitu proses debloat selesai, script akan menyusun file laporan mandiri di folder Desktop pengguna dengan spesifikasi:

Kartu Metrik Delta

Menampilkan angka riil RAM yang berhasil dihemat, jumlah aplikasi yang disingkirkan, dan ruang disk yang dibebaskan.

Grafik Bar Komparasi

Visualisasi grafik batang sebelum vs sesudah pada jumlah proses aktif, background service, dan konsumsi memori.

Kompatibilitas, Keamanan & Restore Point

Script telah diuji stabil pada Windows 10 22H2 dan Windows 11 23H2 / 24H2. Pada awal proses, script secara otomatis membuat System Restore Point berlabel MEGAPASS Debloat v2.4.

Jika sewaktu-waktu Anda ingin mengembalikan kondisi semula, cukup buka System Restore (ketik rstrui.exe di menu Run) dan pilih titik pemulihan tersebut.
